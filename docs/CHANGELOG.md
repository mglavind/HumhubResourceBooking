Changelog
=========

1.0.0 (2026-10-31)
------------------
- Initial release
- Categories and resources with admin management
- Day view with a resource timeline and an agenda layout, both showing every resource for the selected day
- Drag-to-book in the timeline, including prevention of selections over existing bookings
- Compact one-line date and filter toolbar; horizontal scrolling for large resource lists
- Booking creation, editing, cancellation and approval workflow
- Global and per-category booking rules
- Configurable reminder notification before a booking starts
- Conflict detection with configurable buffer
- Timezone-aware booking display
- Global permissions for creating and managing bookings
